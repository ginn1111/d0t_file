## Surface-first specimen

### Design stance
Show editor and terminal use first, with semantic color annotations beside each preview.

### Key choices
- Layout: simulated workspace frame, sidebar, preview, and visible-role inspector.
- Typography: system UI and monospace code sample.
- Color: provisional upstream Evondev Dracula Darker Contrast, plus the local VS Code status-bar override.
- Interaction: editor/terminal toggle updates content and visible roles.

### Trade-offs
- Strong at: evaluating the overall feel and role consistency across surfaces.
- Weak at: listing every color and token on one page.

### Best for
Deciding whether the palette feels right before writing the portable theme specification.
